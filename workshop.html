Abstraction

All networks have:

  • Things that are connected (what)
  • Some type of connection (how)

Basic Terminology

  • Node/Vertex: The things (neurons, people, computers) that are connected.
  • Link/Edge: The connection between things.
  • point/line, actor/tie, site/bond

What is a network?

A connected thing

A network is a model of edges between different nodes.

Networks can have weighted edges

Networks can have directed edges

Many other types of networks

Network representations (visualization)

From visualization to matrix form

Adjacency Matrix (\(A\))

Graph object

A simple graph: \(\mathcal{G} = (\mathcal{V}, \mathcal{E})\).

\(\mathcal{G}\) - is the graph.

\(\mathcal{V}\) - is a set (list) of nodes (V for vertex).

\(\mathcal{E}\) - is a set (list) of edges.

Graph object (practical)

\((Ashley, Blake, Casey) \in \mathcal{V}\)

\(((Ashley,Blake), (Ashley,Casey)) \in \mathcal{E}\)

Different representations, same information

How to make a network

  • Define nodes
  • Define edges
  • (If needed) Infer edges from nodal data.
  • Post processing
  • Quantify
    Many options here

Edge collected data

  • Data: An X2000 train traveled between GBG och STHLM.
  • Network: the edge is between GBG and STHLM.

Node collected data

  • Data: A X2000 train left GBG. A X2000 train arrives at STHLM.
  • Network: infer an edge between GBG and STHLM.

Brain Networks

  • fMRI: we have timeseries from brain areas and infer nodes.
  • EEG/MEG: we have timeseries from sensors or source areas and infer nodes, and then infer edges.
  • DTI: we have anatomical connections between brain areas.

Edge inference:

A non-exhaustive list of methods to infer edges:

Pearson correlations, Spearman correlations, Bayesian estimates, partial (directed) correlations, Ridge/GLasso Regression, Granger Causality, dynamic causal modelling, phase synchrony, transfer entropy, coherence, coherency, phase locking value, weighted phase lag, spike-field coherence, spike correlations, canonical-correlation analysis, Hamming distance.

So which should you choose?

What is the edge trying to quantify / what does the edge mean?

  • Statistical relationship (e.g. Pearson)
  • Direct communication (e.g. coherence)
  • Information sharing (e.g. TE)
  • Causality. (e.g. DCM)
  • The method guides the interpretation. This then effects the interpretation of your network measures.

Adding a Simple Network

# Create an empty graph
G = nx.Graph()

# Add nodes
G.add_nodes_from([1, 2, 3, 4, 5])

# Add edges
G.add_edges_from([(1, 2), (2, 3), (3, 4), (4, 5), (5, 1)])

Adding Weights to the Edges

More commonly, weights are predefined in datasets. Consider the following adjacency matrix:

Ashley Blake Casey Dylan Elliot Finley
Ashley 0 2 0 0 2 1
Blake 2 0 4 0 0 0
Casey 0 4 0 3 0 0
Dylan 0 0 3 0 1 5
Elliot 2 0 0 1 0 0
Finley 1 0 0 5 0 0

Summary / Cheat Sheet

Concept networkx Function
Create network nx.Graph(), nx.from_pandas_adjacency(), nx.from_numpy_matrix()
Network properties G.number_of_nodes(), G.number_of_edges(), G.nodes(), G.edges()
Visualizing network nx.draw(G, with_labels=True, layout=...)
Add nodes/edges G.add_node(), G.add_nodes_from(), G.add_edge(), G.add_edges_from()
Name nodes nx.set_node_attributes(G, {1: "A", 2: "B"}, "name"), nx.get_edge_attributes("name")
Edge weights nx.set_edge_attributes(G, {(1, 2): 5, (2, 3): 8}, "weight"), nx.get_edge_attributes("weight")
Layouts nx.circular_layout(G), nx.random_layout(G), nx.spring_layout(G), etc.
